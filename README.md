# 🌱 VAL Plantios

Uma loja virtual de plantas feita em PHP, HTML, CSS e JavaScript.

A ideia do projeto foi criar uma loja de plantas que tivesse uma experiência mais completa, indo além de apenas mostrar os produtos. O sistema conta com catálogo, pesquisa, carrinho, cadastro e login de usuários, além da integração com banco de dados.

> Projeto desenvolvido para colocar em prática conhecimentos de desenvolvimento web e experimentar a construção de uma aplicação completa, juntando front-end e back-end.

---

## 🪴 Funcionalidades

- 🏠 Página inicial
- 🌿 Catálogo de plantas
- 🔎 Pesquisa de produtos
- 📦 Página de detalhes dos produtos
- 🛒 Carrinho de compras
- ➕ Alteração da quantidade dos produtos
- ❌ Remoção de produtos
- 🎟️ Sistema de cupons
- 🚚 Cálculo de frete
- 👤 Cadastro de usuários
- 🔐 Login e logout
- 💾 LocalStorage para o carrinho
- 🗄️ Integração com banco de dados
- 📱 Interface responsiva
- ✨ Animações e interações com JavaScript e CSS
